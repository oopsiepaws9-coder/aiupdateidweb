# AIUpdateId Public V9.3.7 — Server-First SEO Rendering

Perbaikan utama:
- Homepage mengambil artikel published di server sebelum HTML dikirim.
- Detail artikel mengambil isi artikel dan artikel terkait di server.
- Halaman kategori dan tag dirender dari server.
- Direktori Models, Glossary, dan Compare menerima initial data dari server.
- Tools dan Prompts sebelumnya sudah server-first dan dipertahankan.
- Filter homepage tetap interaktif di client tanpa mengorbankan HTML awal.
- Alias kategori lama/baru didukung agar hasil kategori tidak kosong setelah normalisasi database.
- View counter dipisah ke komponen client agar tidak menghalangi render artikel.
- ISR/revalidate 300 detik dipakai pada halaman data publik utama.

Tujuan: crawler menerima judul, excerpt, link, serta isi artikel langsung pada response HTML awal, bukan hanya placeholder seperti `Mengambil artikel...`.
